## Key Rules
1. Spiral Learning: Every topic connects theory, step-by-step code, gotchas, and capstone synthesis.
2. The Bicycle Rule: Keep explanations actionable with runnable code.
3. Universal README coverage: Every directory must have a README.md explaining its contents with a Mermaid diagram.
4. Clean Root: Do not place maintenance `.py` scripts in the root; keep them in `scripts/`.
5. Testing: Pytest test suites are centralized in `/tests/`.
6. PDFs: Compiled via Google Chrome Headless from HTML using LaTeX typography styles into temporary folders.
