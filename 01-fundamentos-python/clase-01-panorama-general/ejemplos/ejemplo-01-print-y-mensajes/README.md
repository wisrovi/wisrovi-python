# 📑 Ejemplo 01: El Megáfono (La función print)

> **Concepto Clave:** Imprimir texto y números en la consola mediante la función print().  
> **Metáfora:** El Megáfono: La consola de la computadora es una pantalla en blanco y print() es el megáfono para escribir en ella.
