# 🧠 Módulo 1: Estructuras de Datos Avanzadas

Bienvenido al Módulo 1 del Curso 2. Aquí exploraremos cómo organizar grandes volúmenes de información en Python de forma eficiente.

## 📋 Temario
1. **Tuplas y Conjuntos (`sets`):** Operaciones de conjuntos, inmutabilidad y rendimiento.
2. **Diccionarios Anidados:** Modelado de datos complejos tipo JSON.
3. **Pilas (Stacks) y Colas (Queues):** Principios LIFO (Last In First Out) y FIFO (First In First Out).

## 📂 Estructura
- `ejemplos/`: Códigos explicativos con comparaciones de rendimiento.
- `ejercicios/`: Solución de problemas clásicos (validación de paréntesis, colas de atención, etc.).
