# 🗄️ Plantilla: Sistema de Gestión con Base de Datos

Estructura sugerida para construir un sistema CRUD (Crear, Leer, Actualizar, Eliminar).

## 📁 Estructura Sugerida
```text
sistema-gestion/
├── main.py              # Interfaz de consola o GUI
├── database.py          # Conexión y consultas a la base de datos (SQLite / PostgreSQL)
├── models.py            # Modelos de datos
└── requirements.txt
```
