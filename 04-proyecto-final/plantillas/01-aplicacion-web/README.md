# 🌐 Plantilla: Aplicación Web con Python

Estructura sugerida para construir una aplicación web usando Python (Streamlit / Flask / FastAPI).

## 📁 Estructura Sugerida
```text
mi-app-web/
├── app.py               # Punto de entrada principal
├── requirements.txt     # Dependencias del proyecto
├── config.py            # Configuraciones
├── static/              # Estilos CSS e imágenes
└── templates/           # Vistas HTML (si aplica)
```
