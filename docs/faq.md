# ❓ Preguntas Frecuentes (FAQ)

---

### 1. ¿Necesito conocimientos previos en programación para empezar?
No. El **Curso 1: Fundamentos Básicos de Python** está diseñado 100% para principiantes absolutos. Comenzaremos desde cero sin asumir ningún conocimiento previo.

### 2. ¿Qué pasa si un sábado no puedo conectarme en vivo por Zoom?
No te preocupes. Todas las clases se graban y se suben a **YouTube**. Podrás verla a tu ritmo y realizar las preguntas que tengas en el grupo del curso.

### 3. Mi comando `python` me da un error en la terminal, ¿qué hago?
- Si estás en macOS o Linux, prueba ejecutando `python3 nombre_archivo.py`.
- Si estás en Windows, asegúrate de haber marcado la casilla *"Add Python to PATH"* durante la instalación de Python. Si no lo hiciste, reinstala Python marcando esa opción.

### 4. ¿Cómo ejecuto un archivo de Python desde VS Code?
1. Abre la carpeta del curso en VS Code (`File > Open Folder...`).
2. Abre el archivo `.py` que deseas ejecutar.
3. Haz clic en el botón **Play ▶** en la esquina superior derecha o abre la terminal integrada (``Ctrl + ` ``) y ejecuta:
   ```bash
   python nombre_del_archivo.py
   ```

### 5. ¿Cómo será el Proyecto Final del Curso 4?
En el Curso 4 elegirás un proyecto real personalizado según tus intereses:
- Una página web funcional.
- Un chatbot automatizado para atención a clientes.
- Un sistema de gestión con bases de datos.

Contarás con acompañamiento paso a paso, revisión de arquitectura y guía directa para escribir tu código.
