# 📌 Guía de Registro en GitHub

> **Paso obligatorio previo a la primera clase.**
> *Tiempo estimado: 2 minutos.*

---

## ⚡ ¿Qué es GitHub y por qué lo usamos?

**GitHub** es la plataforma estándar global donde los desarrolladores guardamos, organizamos, compartimos y colaboramos en nuestro código fuente. 

Durante este programa de 4 cursos, GitHub será tu cuaderno de notas digital y tu portafolio personal de proyectos.

---

## 🛠️ Pasos para crear tu cuenta

1. **Ingresa a la página oficial:**
   Abre tu navegador e ingresa a [https://github.com](https://github.com).

2. **Haz clic en "Sign up" (Registrarse):**
   Ubicado en el botón azul de la esquina superior derecha.

3. **Ingresa tus datos:**
   - 📧 **Correo electrónico:** Utiliza tu correo personal o profesional de uso habitual.
   - 🔐 **Contraseña:** Crea una contraseña segura.
   - 👤 **Nombre de usuario (Username):** 
     > 💡 **Consejo clave:** Elige un nombre sencillo y profesional (por ejemplo: `juan-perez`, `maria-gomez-dev` o `luisgarcia`). Evita apodos informales, ya que este perfil te servirá para mostrar tus proyectos a reclutadores o colegas.

4. **Verificación de seguridad:**
   Resuelve el pequeño acertijo/puzzle visual para verificar que eres una persona real.

5. **Código de verificación:**
   Revisa tu bandeja de entrada de correo electrónico. Copia el código de 6 u 8 dígitos enviado por GitHub e ingrésalo en la página.

¡Listo! Ya tienes tu cuenta activa. 🎉

---

## 🎯 Siguientes pasos

Una vez creada tu cuenta:
1. No necesitas instalar nada más por el momento.
2. Anota tu **nombre de usuario** para compartirlo en la primera clase.
3. Continúa con la [Guía de Instalación de VS Code](guia-vscode.md).
